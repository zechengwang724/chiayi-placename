# chiayi-placename

嘉義古蹟與古地名網站雛形。靜態網頁，不需要伺服器，直接用瀏覽器打開 `index.html` 即可瀏覽。

> 目前內容皆為**範例資料**：耆老為虛構人物，照片為示意圖，錄音為合成語音。

## 資料夾

| 資料夾 | 內容 |
|---|---|
| `index.html` | 網站入口 |
| `資料庫/` | 地名、古蹟、耆老訪談三個 Excel |
| `照片/` `錄音/` `文件/` | Excel 中登記的檔案，依檔名對應 |
| `系統/` | 網頁程式、樣式、地圖程式庫，以及產生資料的 `build.py` |

## 更新資料

修改 `資料庫/` 裡的 Excel，或新增照片、錄音、文件後，在此資料夾執行：

```
python3 系統/build.py
```

程式會重新產生 `系統/data.js`，並在 `系統/檢查報告.txt` 列出找不到的檔案和無法連結的地名。

照片或錄音不在時，網頁會顯示「照片未提供」「錄音未提供」的預設空框。

底圖：內政部國土測繪中心臺灣通用電子地圖（需連網）。
